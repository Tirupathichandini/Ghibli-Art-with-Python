# Ghibli Art Generator

A Python project to transform images into **Studio Ghibli-style art** using image processing techniques. This project applies filters and effects to give your photos a whimsical, Ghibli-inspired aesthetic.



## Features

- **Cartoon / Ghibli Effect**: Convert ordinary images into Ghibli-style artwork.
- **Customizable Filters**: Adjust parameters like color, contrast, and smoothing.
- **Supports Multiple Images**: Batch process images easily.
- **User-Friendly Interface**: Simple Python script that can be run from the console or integrated with a GUI.



## Technologies Used

- **Programming Language:** Python 3.x  
- **Libraries:**
  - `OpenCV` – for image processing
  - `NumPy` – for numerical operations
  - `Pillow` – for image handling
  - `matplotlib` – for displaying images (optional)
